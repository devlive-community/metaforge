---
title: 同步历史
---

在数据集列表每行末尾的菜单里点击 `同步历史`，进入数据集的同步记录页。

记录页包含手动同步和定时任务同步的所有记录：

- `概览`：状态、耗时、开始和结束时间、各阶段耗时和状态变化记录。同步失败时会显示错误信息。
- `运行指标`：进度、吞吐、分片进度和被拒绝的行，含义见 [同步执行器](../executor/home.html)。
- `运行日志`：这次同步的任务日志。
- `历史同步`：所有同步记录，点击编号切换到对应的记录。

页面顶部的按钮对当前选中的记录生效：运行中可以 `暂停` 或 `停止`，已暂停可以 `继续` 或 `取消`，失败或已停止的同步在满足条件时可以 `从断点重新运行`。
