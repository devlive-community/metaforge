We are thrilled to announce the release of MetaForge 2026.0.0! This is a milestone release: a brand-new source management workbench, a visual screen studio, an IDE-style query console, a reworked sync engine and notification center, plus new data source drivers and GitHub / Google / OIDC sign-in support. This release ships more than 700 improvements.

## 📅 Release Information

- **Version**: 2026.0.0
- **Release Date**: November 9, 2026
- **Project**: https://github.com/devlive-community/metaforge
- **Website**: https://metaforge.devlive.org/

## 🎯 Highlights

### 🗄️ Source Management Workbench (fully rebuilt)

- **New workbench**: The source management experience is fully redesigned — table structure, data preview, DDL, indexes, foreign keys, triggers and table properties, all in one place
- **Full metadata DDL**: View / create / change / drop indexes, foreign keys and triggers; read and write table properties with a history of generated DDL
- **ER diagrams**: Whole-database and per-table ER diagrams with dependent-object listing
- **Structure and data compare**: Compare the structure and the data of two tables
- **Column dependency detection**: Objects depending on a column are listed before it is dropped
- **Data editing**: Typed form / JSON row editing, Shift-range row selection, sorting with up to five rules, drag-to-resize columns
- **Capability awareness**: The UI shows only the management operations each source plugin declares

### 🔍 Query Console (IDE-style rebuild)

- **IDE-style three-pane layout**: Resizable panes with a persisted layout
- **Visualization upgrade**: Result visualization moves to ECharts with new chart controls
- **Query plans**: Supported engines can execute and display the query execution plan
- **Results to datasets**: Create a dataset from query results with one click
- **Row limit**: Query page results are capped at a row limit to keep large results responsive
- **Templates and shortcuts**: The snippet library appears as a template tab, Cmd+Enter runs the query, and you can execute just the selected SQL

### 🖥️ Visual Screen Studio

- **Complete visual studio**: A full designer for boards and data screens
- **Widget families**: Dozens of new widget families — business analytics, operations and inspection, time series, spatial analysis, process tracking, interval analysis, data diagnostics, relationship analysis, planning and progress, comparative analysis — plus many new chart types (stacked, step, bubble and more)
- **Effects and motion**: Flow effects, geometric effects and widget motion presets, previewable on the canvas
- **Sharing and public access**: Data screens support public links and can be shared with users, roles or everyone
- **Screen as home page**: Any data screen can become the home page, with a toolbar-free full view
- **Component gallery**: A searchable gallery with static previews lets you browse while choosing

### 📊 Datasets and the Sync Engine

- **Dataset console rework**: A new ad-hoc query workspace with inline column type configuration
- **Sync history**: Live total / completed / progress counters, dataset statistics refreshed during the run, live and finished run logs, and manual sync stop
- **Sync engine upgrade**: Queued tasks with state and metrics, parallel read channels with a rate limit, write-failure tolerance with pause / resume / retry, whole-task timeouts, and unfinished syncs marked INTERRUPTED after a restart
- **Streaming sync**: The local executor streams large tables (fixing OOM / SQL injection / NULL handling) and writes standalone task logs

### 📥 Import and Export

- **Export wizard**: Data export is rebuilt as a five-step wizard; database exports run as background jobs
- **File import**: A new file import flow — analyse, preview and run the import into a database
- **Table data export**: Table rows export to files through the convert plugins

### 🔌 Drivers and Data Sources

- **New drivers**: Kafka, ZooKeeper, Aliyun OSS and HDFS JDBC drivers
- **Redis driver rewritten**: Redis is described as databases, keys and columns, with native keyspace browsing
- **Non-SQL sources**: A JDBC driver foundation for sources without SQL
- **MongoDB / Neo4j**: Native browsing of databases, collections / labels and field properties
- **Table options**: CREATE TABLE options are passed through to sources

### 🔔 Notification Center

- **Notifications rebuilt**: A bell-panel notification center organized around channels and scenes
- **Per-user inbox**: A per-user notification inbox API
- **Scene notices**: Sources, reports and accounts raise scene notices, and each user configures channel settings independently

### 📡 Report Sharing

- **Public links**: Reports are shared through public links and iframe embeds
- **Sharing controls**: Link expiry and a choice of what the public page shows
- **Data download**: The public page can offer its data and a CSV download

### 🔐 Authentication and Accounts

- **Third-party sign-in**: GitHub, Google and OpenID Connect (OIDC) sign-in
- **Feature switches**: Administrators control whether sign-in and sign-up are enabled
- **Roles**: Unified role management with validated custom codes that cannot be changed afterwards
- **Sign-in log**: The sign-in log shows the failure message

### 🧰 First-Boot Setup and System Configuration

- **Setup wizard**: The server boots without a database and finishes installation in the wizard
- **More databases**: The wizard installs into PostgreSQL, SQL Server and Oracle
- **Common configuration**: A datacap_configure table and an administrator configuration page
- **File storage**: File storage is configured in system settings and tested before saving

### 🎨 Interface and Experience

- **Component library**: The new metaforge-ui Tailwind component library with a design-token theme system and an ant-design-vue foundation
- **Navigation rebuild**: User and admin pages are separated; menus are managed from the menu table
- **Home redesign**: A new resource workspace with query activity charts and recent resources
- **Branding**: Global header search, branded assembly loading animation, wave background and logo empty states

### 🛍️ Plugin Store

- **Store rebuilt**: The plugin store gets a completely refreshed interface and fetches the catalogue through the server
- **Safe management**: Plugins are managed safely, verified downloads are counted and details are shown

## 🛠️ Important Fixes

- **Sync engine**: Fixed OOM, SQL injection and NULL handling in streaming sync
- **Persistence**: Fixed the Oracle / SQL Server matrix runs and the upgrade of databases that ran edited changesets
- **Query tree**: The query page tree lists only tables and views; ClickHouse lists user-defined functions only
- **Source plugins**: Fixed issues in YDB (scheme queries), TDengine, Solr, Presto, Pinot, IoTDB, InfluxDB, Doris and more
- **Interface**: Fixed about 50 UI issues (dropdowns, overlapping legends, calendar localization, chart clipping and more)

## 🔧 System Optimizations

- **Refactoring**: 100+ refactorings, including reusable screen components, a shared filter-table layout for paginated lists, and capability declarations in the plugin contract
- **Release infrastructure**: Maven Central publishing, Tencent COS CDN distribution and ForgeStats download statistics
- **CI**: Change-scoped jobs, memory and disk governance for the backend suite

## 🗑️ Removals

- **Plugin cleanup**: The ClickHouse HTTP and CrateDB HTTP plugins are removed (use the corresponding standard plugins)
- **Query tree**: The key-value mode of the query page tree is removed
- **Legacy code**: 17 unreachable web source files and the retired runtime settings menu entry are cleaned up

## 🚀 Upgrade Guide

1. **Back up your data**: Always back up your data and configuration before upgrading
2. **Stop the service**: Stop the running MetaForge service
3. **Update**: Download the latest 2026.0.0 distribution
4. **Database upgrade**: Versioned database migrations run automatically at startup (multi-database changelog built in)
5. **First install**: A fresh deployment boots without a database and finishes setup in the wizard
6. **Restart**: Start the new version and verify

## 📝 Notes

- The ClickHouse HTTP and CrateDB HTTP plugins are removed; migrate to the corresponding standard plugins
- Legacy Redis source types migrate automatically to the new driver configuration at startup
- The interface changed substantially; if you rely on custom board or report layouts, verify them in a staging environment first
- The new third-party sign-in (GitHub / Google / OIDC) must be enabled in system configuration with the corresponding credentials
