我们很高兴地宣布 MetaForge 2026.0.0 版本正式发布！这是一个里程碑版本：全新数据源管理工作台、可视化大屏工作室、IDE 风格查询控制台、重构的同步引擎与通知中心，并新增多种数据源驱动与 OAuth / OIDC 登录支持。本次更新共包含 700 余项改进。

## 📅 发布信息

- **版本号**: 2026.0.0
- **发布日期**: 2026年11月9日
- **项目地址**: https://github.com/devlive-community/metaforge
- **官方网站**: https://metaforge.devlive.org/

## 🎯 版本亮点

### 🗄️ 数据源管理工作台（全新重构）

- **全新工作台**: 数据源管理体验全面重构——表结构、数据预览、DDL、索引、外键、触发器、表属性一站式管理
- **完整元数据 DDL**: 支持索引、外键、触发器的查看 / 创建 / 修改 / 删除，支持读写表属性并保留 DDL 生成历史
- **ER 图**: 支持数据库整体 ER 图与表级 ER 图，可查看依赖对象列表
- **结构与数据对比**: 支持对两张表的结构和数据进行对比
- **列依赖检测**: 删除字段前展示依赖该列的对象，避免误删
- **数据编辑增强**: 类型化表单 / JSON 双模式编辑数据行、行选择支持 Shift 范围、最多五条规则排序、列宽拖拽调整
- **能力感知**: 界面按各数据源插件声明的能力动态展示可用的管理操作

### 🔍 查询控制台（IDE 化重做）

- **IDE 风格三栏布局**: 控制台重构为可调宽度的三栏布局，布局自动记忆
- **可视化升级**: 结果可视化迁移到 ECharts，新增图表控件
- **查询计划**: 支持的引擎可执行并展示查询执行计划
- **结果转数据集**: 查询结果一键创建数据集
- **结果上限**: 查询页结果按行数上限截断，避免大数据量拖垮前端
- **模板与快捷操作**: 片段库作为模板 Tab 展示、支持 Cmd+Enter 执行、可只执行选中的 SQL

### 🖥️ 可视化大屏工作室

- **完整可视化工作室**: 面向仪表板与大屏的完整设计器
- **组件家族**: 新增业务分析、运营巡检、时间序列、空间分析、流程跟踪、区间分析、数据诊断、关系分析、规划进度、对比分析等数十个 Widget 家族，以及堆叠 / 步进 / 气泡等大量新图表类型
- **特效与动效**: 新增流动特效、几何特效、组件动效预设，可在画布上预览动画
- **分享与公开**: 数据大屏支持公开链接，可分享给用户、角色或所有人
- **大屏主页**: 可将数据大屏设为首页，支持无工具栏的全屏视图
- **组件画廊**: 可搜索的组件画廊带静态预览，边浏览边挑组件

### 📊 数据集与同步引擎

- **数据集控制台重做**: 全新 Ad-hoc 查询工作区，支持内联配置列类型
- **同步历史**: 实时展示总数 / 已完成 / 进度，同步期间实时刷新数据集统计，支持查看实时与历史运行日志、手动停止同步
- **同步引擎升级**: 任务队列化并跟踪状态与指标、多通道并行读取（带速率限制）、写失败容忍并支持暂停 / 恢复 / 重试、整任务超时控制、服务重启后将未完结同步标记为 INTERRUPTED
- **流式同步**: 本地执行器支持流式同步，修复大表同步 OOM / SQL 注入 / NULL 处理问题，输出独立任务日志

### 📥 导入与导出

- **导出向导**: 数据导出重构为五步向导，支持数据库导出作为后台任务执行
- **文件导入**: 全新文件导入流程——分析、预览、执行导入到数据库
- **表数据导出**: 表数据可通过转换插件导出为文件

### 🔌 驱动与数据源支持

- **新增驱动**: Kafka、ZooKeeper、阿里云 OSS、HDFS JDBC 驱动
- **Redis 驱动重写**: 按数据库、键、列描述 Redis，支持原生浏览键空间
- **无 SQL 数据源**: 新增面向无 SQL 数据源的 JDBC 驱动基础
- **MongoDB / Neo4j**: 原生浏览数据库、集合 / 标签与字段属性
- **建表选项**: CREATE TABLE 选项可透传到数据源

### 🔔 通知中心

- **通知重构**: 铃铛面板式通知中心，围绕渠道 + 场景体系组织
- **每用户收件箱**: 新增按用户的通知收件箱 API
- **场景通知**: 数据源、报表、账户等场景自动触发通知，每个用户可独立配置渠道设置

### 📡 报表分享

- **公开链接**: 报表支持通过公开链接和 iframe 嵌入分享
- **分享控制**: 链接过期时间、公开页展示内容自由选择
- **数据下载**: 分享页可提供原始数据与 CSV 下载

### 🔐 认证与账户

- **第三方登录**: 新增 GitHub、Google 和 OpenID Connect（OIDC）登录
- **注册开关**: 管理员可控制系统登录与注册功能的开启状态
- **角色管理**: 角色管理统一化，支持带校验的自定义角色码并禁止修改角色码
- **登录日志**: 登录日志展示失败原因

### 🧰 首次安装与系统配置

- **安装向导**: 服务可在无数据库状态下启动，通过首次安装向导完成初始化
- **更多数据库**: 安装向导支持 PostgreSQL、SQL Server 和 Oracle
- **通用配置**: 新增 datacap_configure 通用配置表与管理员系统配置页面
- **文件存储**: 系统设置中可配置文件存储，保存前支持连通性测试

### 🎨 界面与体验

- **组件库**: 全新 metaforge-ui Tailwind 组件库与 Design Token 主题体系，引入 ant-design-vue 基础
- **导航重构**: 用户页面与管理页面分离，菜单改为从菜单表管理
- **首页重做**: 全新资源工作区，新增查询活动图表与最近资源
- **品牌化**: 全局头部搜索、品牌加载动画、品牌波浪背景与 Logo 空状态

### 🛍️ 插件商店

- **商店重做**: 插件商店界面全面翻新，插件目录改为通过服务器获取
- **安全安装**: 更安全的插件管理，统计经过验证的下载量，展示插件详情

## 🛠️ 重要修复

- **同步引擎**: 修复流式同步的内存溢出（OOM）、SQL 注入与 NULL 值处理问题
- **持久化**: 修复 Oracle / SQL Server 矩阵测试与已执行过变更集数据库的升级问题
- **查询树**: 查询页目录树只展示表和视图；ClickHouse 仅列出用户自定义函数
- **数据源插件**: 修复 YDB（scheme 查询）、TDengine、Solr、Presto、Pinot、IoTDB、InfluxDB、Doris 等插件的多项问题
- **界面**: 修复约 50 项 UI 问题（下拉菜单、图例遮挡、日历本地化、图表裁剪等）

## 🔧 系统优化

- **重构**: 100 余项重构，包括可复用大屏组件抽取、分页列表统一过滤-表格布局、插件契约能力声明
- **发布基建**: Maven Central 发布流程与腾讯云 COS CDN 分发、ForgeStats 下载统计
- **CI**: 按改动范围运行对应检查任务、后端套件内存与磁盘治理

## 🗑️ 功能移除

- **插件清理**: 移除 ClickHouse HTTP 与 CrateDB HTTP 插件（请使用对应的标准插件）
- **查询树**: 移除查询页树的键值（key-value）模式
- **遗留代码**: 清理 17 个不可达的 Web 源文件与退役的运行时设置菜单入口

## 🚀 升级指南

1. **备份数据**: 升级前请务必备份您的数据和配置文件
2. **停止服务**: 停止当前运行的 MetaForge 服务
3. **更新版本**: 下载最新的 2026.0.0 版本文件
4. **数据库升级**: 启动时自动执行版本化数据库迁移（内置多数据库 changelog）
5. **首次安装**: 新部署将在无数据库状态下启动，通过安装向导完成初始化
6. **重启服务**: 启动新版本服务并验证功能

## 📝 注意事项

- 本版本移除了 ClickHouse HTTP 与 CrateDB HTTP 插件，请迁移到对应的标准插件
- 旧版 Redis 数据源类型将在启动时自动迁移到新的驱动配置
- 本版本界面改动较大，如使用了自定义大屏或报表布局，建议升级前在测试环境完整验证
- 新增的第三方登录（GitHub / Google / OIDC）需要在系统配置中开启并填写对应凭证
